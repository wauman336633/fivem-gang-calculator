# FiveM 強盗報酬計算ツール (FiveM Gang Heist Calculator)

FiveM内の強盗ミッションにおける報酬精算（純利益計算、ギャングプール配分、罰金・個人医蘇生費用の補填計算）を素早く行い、ゲーム内送金用の数値やDiscord報告用テキストをワンクリックでコピーできるWeb電卓です。

マテリアルデザインのダークテーマ（Material Dark / 深色スレート基調）を採用し、長時間のゲームプレイや夜間、PC・スマートフォン・ゲーム内オーバーレイブラウザでの利用において眩しさを抑え、数値が見やすい設計になっています。

---

## 🚀 主な機能

- **パターン出力型計算**
  - 人数と金額を入力するだけで、「無事な人（通常配分）」「罰金がある人」「個人医蘇生の人」「ギャングプール」の4つの金額パターンを即時算出。
- **実戦的な1,000ドル未満切り捨て & プール集約**
  - ゲーム内送金の手間を軽減するため、メンバーへの配分額は **1,000ドル未満を自動切り捨て**。
  - 切り捨てによって生じた端数はすべて自動的に **ギャングプール（組織金庫）** に加算されるため、支給総額は総利益と1ドルも狂わず完全一致します。
- **赤字（経費超過）対応**
  - 罰金や蘇生費用が総利益を上回った場合、赤字バッジで不足額を表示し、通常配分を0ドルとして実費計算および組織負担額を明確化。
- **入力サポート**
  - 個人医蘇生費用：**「100万 ($1,000,000)」 / 「300万 ($3,000,000)」** のワンタップ入力ボタン。
  - 罰金単価などの前回入力値をブラウザ（LocalStorage）に自動保存。
- **ワンクリックコピー機能**
  - 各配分枠の横にある「数字コピー」ボタンで、ゲーム内ATMや送金欄にそのまま貼り付け可能な **数字のみ** をコピー。
  - 画面下部の「報告テキストを一括コピー」ボタンで、**Discordの報告チャンネルにそのまま貼れる整形テンプレート** を一発出力。

## 📐 計算ロジック

1. **経費総額** ＝ (1人の罰金金額 × 捕まった人数) ＋ (1人の蘇生費用 × 個人医蘇生人数)
2. **純利益** ＝ 総利益 － 経費総額
3. **分配枠数** ＝ 参加人数 ＋ 1（ギャングプール枠）
4. **1人あたりの配分額** ＝ `Math.floor((純利益 / 分配枠数) / 1000) * 1000`
5. **支給金額パターン**：
   - 🟢 **通常配分（無事な人）** ＝ 1人あたりの配分額
   - 🚔 **罰金がある人** ＝ 1人あたりの配分額 ＋ 罰金金額（実費補填）
   - 🚑 **個人医蘇生の人** ＝ 1人あたりの配分額 ＋ 蘇生費用（実費補填）
   - 🏦 **ギャングプール** ＝ 純利益 － (1人あたりの配分額 × 参加人数)
     - ※基本配分枠 ＋ 切り捨てられた端数の合計がすべてプールに入ります。

## 🌐 GitHub Pages での公開手順

本ツールはビルド不要（HTML単一ファイル）で動作するため、以下の手順ですぐに公開できます。

1. 本リポジトリの変更をGitHub（`main` ブランチ）にプッシュします。
   ```bash
   git add .
   git commit -m "feat: Add FiveM heist calculator"
   git push origin main
   ```
2. GitHubのリポジトリページを開き、**「Settings」** タブをクリックします。
3. 左メニューの **「Pages」** を選択します。
4. **「Build and deployment」** の設定で以下を選択します：
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/(root)`
5. **「Save」** をクリックします。
6. 数分後、`https://<ユーザー名>.github.io/fivem-gang-calculator/` にてツールが公開されます。
